# StreakForge 🔥

> A lightweight, fast developer streak tracker, focus timer, and habit builder designed to keep your momentum going every single day.

---

## ✨ Features

- 📅 **Interactive Streak Heatmap**: Real-time visual activity grid mirroring GitHub-style contributions.
- ⏱️ **Integrated Focus Timer**: Built-in Pomodoro timer with customizable intervals and procedural sound alerts (Web Audio API).
- 🎯 **Daily Objective Tracker**: Quick-add daily goals, tasks, and habit milestones.
- 📊 **Streak Metrics & Insights**: Live tracking of current streak, longest streak, and total completed sessions.
- 💾 **Local-First & Private**: Zero cloud dependency; all progress is safely persisted to `localStorage` with JSON export/backup capability.
- ⚡ **Zero-Build & Ultra-Fast**: Pure vanilla web stack (HTML5 / CSS3 / Vanilla JS). No bundlers or heavy dependencies required.

---

## 🚀 Quick Start

Simply clone the repository and open `index.html` in your favorite browser:

```bash
git clone https://github.com/HunainAhmed/streak-forge.git
cd streak-forge
# Open index.html directly or serve with python:
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) to view it in action.

---

## 🛠️ Tech Stack

- **HTML5 & Modern CSS**: Responsive CSS Grid / Flexbox with dark mode glassmorphism aesthetic.
- **Vanilla JavaScript (ES6+)**: Clean, modular application architecture.
- **Web Audio API**: Synthetic audio chimes for timer alerts without external asset dependencies.
- **LocalStorage API**: Instant client-side persistence.
